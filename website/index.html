FROM ZERO TO SHELLIX

Your next session
starts here.

A Linux terminal, Python 3.11 or newer, internet access, and an OpenRouter account. That’s your starting point.

Explore release 0.1.2 ↗
ⓘ

Recommended: pipx automatically uses Shellix’s separate environment. Run shellix from any folder without manually activating it. Your current project environment stays unchanged. These commands are for Bash or Zsh.

01 Check your Python version

python3 --version

Shellix requires Python 3.11 or newer.

02 Install pipx on Ubuntu

sudo apt update
sudo apt install pipx
pipx ensurepath

Close and reopen your terminal afterward so it can find commands installed by pipx.

03 Install Shellix

pipx install shellix-ai

This uses pipx’s default Python, which must be 3.11 or newer. If it is too old, select an existing newer Python using the troubleshooting steps below.

04 Verify and launch

shellix --version
shellix

05 Complete first-run setup

Enter your OpenRouter API key and an exact OpenRouter model ID when prompted. Model availability and pricing depend on OpenRouter. See setup details below.

06 Change your key or model

shellix configure

07 Fix code inside a project

cd /path/to/project
shellix fix

Replace /path/to/project with your project’s folder. Describe the issue, optionally paste terminal errors, approve sending project context, and review the proposed diff. Choose Apply or Reject, or open Vim to review/edit the proposal before approving the revised diff. After applying, Shellix prints an undo command you can use to review and approve a reversal.

08 Upgrade Shellix

pipx upgrade shellix-ai

Installation troubleshooting

Python version is too old

Python 3.10 cannot install Shellix. Select an existing Python 3.11 or newer, replacing the placeholder with its absolute path:

pipx install --python /absolute/path/to/python shellix-ai

Optional Miniconda example: check the version first and continue only if it is 3.11 or newer.

"$HOME/miniconda3/bin/python" --version
pipx install --python "$HOME/miniconda3/bin/python" shellix-ai

This path applies only if Miniconda is installed there. Whichever Python you select, that Python installation must remain available for Shellix to work.

Already installed using pip

Run this in the environment where the old package is installed:

python -m pip uninstall shellix-ai

Removing the package preserves your saved API key/model settings. Then follow the pipx installation steps above.

shellix command not found
pipx ensurepath

Close and reopen your terminal, then try shellix again.

Optional alternative: a virtual environment

If you prefer to manage the environment yourself, use Python 3.11 or newer:

python3 -m venv ~/.venvs/shellix
source ~/.venvs/shellix/bin/activate
python -m pip install shellix-ai
shellix

For this alternative, activate the environment again in each new terminal:

source ~/.venvs/shellix/bin/activate
shellix

To upgrade this installation:

source ~/.venvs/shellix/bin/activate
python -m pip install --upgrade shellix-ai

Run deactivate to leave the environment.

NO BLACK BOX PROMISES

Know what happens.
Know the limits.

AI assistance works best
with informed decisions.

01. Local settings, remote AI

Settings live at $XDG_CONFIG_HOME/shellix/config.json, or ~/.config/shellix/config.json when that variable is unset, empty, or relative. The API key is plaintext, protected by directory permissions 0700 and file permissions 0600, not encryption.

Command requests send your prompt, OS, shell, and working-directory path to OpenRouter. Fix requests send the problem, pasted errors, and selected files’ full contents after consent. Model usage may cost money.

02. Checks, with boundaries

The validator uses patterns, not a sandbox. Critical matches are blocked; medium/high matches need confirmation; SAFE commands execute automatically. Dangerous expressions can evade checks.

Ignored files, common secrets, symlinks, hard links, and binary files are excluded from fix context. Secret detection is heuristic and imperfect. Review the file list and remove secrets before sharing. Model output can be wrong.

03. Focused file editing

Fix mode edits existing UTF-8 text files only: no creation, deletion, renaming, or permission changes. Git is required for ignore rules. Limits: 40 files, 128 KB total, 32 KB per file, and 16 KB of problem/errors; scanning stops after 2,000 entries. Relevant files may be omitted.

It’s one proposal and review cycle. Errors must be pasted manually; Shellix does not watch other terminals or act as a full IDE or autonomous coding agent.

04. Approval and recovery

Review controls: Ctrl-A applies, Ctrl-R rejects, Ctrl-V opens Vim; Tab switches panes. Vim edits a temporary proposal. Test commands require separate approval and are not sandboxed.

Undo stores before/after contents in .shellix-undo/<id>.json (directory 0700, files 0600). Keep records private and out of version control; they remain until manually removed.

More execution and file-write limitations

Commands run in a subprocess; a generated cd does not change your terminal’s directory. File replacements are individually atomic, but a multi-file apply is not one filesystem transaction. Avoid concurrent writers: a small race remains after the final stale-file check. Permissions are retained, but ownership, ACLs, extended attributes, and inode identity are not. Interrupted applies retain an undo record and attempt rollback. Settings do not use project .env files or OPENROUTER_API_KEY / OPENROUTER_MODEL environment variables.

A FEW GOOD QUESTIONS

Before you
open a terminal.

Which systems and Python versions are supported?

Shellix is designed for Linux and requires Python 3.11 or newer. The installation examples use Bash or Zsh. Fix mode needs Git and an interactive terminal.

Do I need an API key? Is it free?

Yes, an OpenRouter-issued API key is required for AI requests. Shellix is MIT licensed, but model usage may incur charges. Check current model pricing and your OpenRouter account. This also applies to NVIDIA models accessed through OpenRouter.

Can I change the model later?

Run shellix configure. Enter an exact OpenRouter model ID. Leave the key blank to retain it, or press Enter at the model prompt to retain the displayed default. Canceling before save preserves your existing settings.

Does every command ask for my approval?

No. Commands classified SAFE by the local pattern validator execute automatically. Recognized medium/high risks require confirmation, and critical patterns are blocked. Code edits and optional post-fix test commands require approval.

Do I have to use Vim?

No. You can review the diff and apply or reject without Vim. If you choose Ctrl-V, Vim must be installed. It opens a temporary proposal; after exiting Vim, review the new diff and make a fresh Apply decision.

How does fix mode receive an error?

You paste it yourself at the error> prompt after running shellix fix. Finish with a line containing only .; enter . immediately to skip errors. Shellix does not automatically detect failures in another terminal.

How do I upgrade or fix “command not found”?

For the recommended pipx installation, upgrade with pipx upgrade shellix-ai. If the command is not found, run pipx ensurepath, then close and reopen your terminal. Check with shellix --version. No manual environment activation is needed. For other installation options, see the installation guidance.
